# AI Meme Collage for Hermes

Create dense AI/crypto/Twitter-style meme collage prompts and workflows for Hermes.

This skill is designed for white-background wojak brainrot, bell-curve/IQ-distribution charts, chaotic captions, founder/investor caricature jokes, and terminally-online narrative maps.

## Install

Install directly from this GitHub repo with Hermes:

```bash
hermes skills install thursdaycapital/meme-collage/ai-meme-collage \
  --category creative \
  --yes
```

Restart Hermes after installation so the skill is picked up.

The skill installs as:

```text
~/.hermes/skills/creative/ai-meme-collage/SKILL.md
```

## Use

After installing, invoke it explicitly:

```text
Use $ai-meme-collage to make an absurd AI agents meme collage about coding agents replacing standups.
```

Or describe the desired meme style naturally:

```text
Make a chaotic wojak bell-curve meme poster about data center stocks going brrrr.
```

## What It Helps With

- AI/crypto meme collage concepts
- Wojak, soyjak, NPC, doomer, founder, VC, and degen archetypes
- Bell-curve/IQ-distribution meme layouts
- High-density caption packs with big slogans and tiny zoom-in jokes
- Bilingual meme workflows where Chinese captions are overlaid after image generation
